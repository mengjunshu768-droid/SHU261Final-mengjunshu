- **场景类型**：虚构游戏场景（Cyberpunk 都市）
- **场景图片**：`Final_场景图片/场景图_赛博朋克雨夜.jpg`（16:9 概念图）
- **音频素材**：`Final_音频素材/素材_48k24bit/`（8 个文件，均为 48kHz / 24bit / stereo wav，已去除 AIGC 语音水印；床声 58.30s，随机声 1.9~4.9s）

## 场景描述

雨夜的赛博朋克都市街道。潮湿的沥青路面倒映着高耸摩天楼外墙的全息霓虹广告，品红、青蓝与橙黄的光带在积水中流动；一辆悬浮反重力载具从街道上空缓缓驶过，尾灯划出光带；远处天际线被冷蓝色雨幕笼罩，飞行器剪影在雾气中穿梭。一名穿深色雨衣的行人撑着伞，踏着积水走向街道深处。

## 声音设计说明

### 基底持续声（1 个，>30s，无缝循环）
`bed_cyberpunk_street_60s.wav`（58.30s，>30s，无缝循环；AIGC 原始输出已去除头部平台语音水印后重新导出，文件仍为 48kHz/24bit/stereo）
三层混合：**持续雨声**（自然层）+ **远处城市车流底噪**（环境层）+ **霓虹灯与电子设备电流嗡鸣**（合成层）。三层保持恒定能量，避免出现单体事件声，适合作为场景环境基底并无缝循环。

### 间断随机声（7 个，进入 Random Container）
| 文件 | 内容 | 设计意图 |
|---|---|---|
| one_shot_hovercar_flyby.wav | 飞行车高速掠过头顶（由远及近再远去） | 中距移动源，演示 Position 移动感 |
| one_shot_hovercar_pass.wav | 悬浮载具低速驶过湿街（左→右） | 近距移动源，演示声像平移 |
| one_shot_siren_far.wav | 电子警笛由远及近再渐远 | 远距源，演示距离衰减 |
| one_shot_footsteps_walk.wav | 皮靴踩水步行 | 近距点源，随机触发频率高 |
| one_shot_footsteps_run.wav | 急促奔跑踩水 | 近距点源，节奏变化 |
| one_shot_hologram_blip.wav | 全息广告电流滴答 | 近距电子点源 |
| one_shot_distant_rumble.wav | 远处低沉闷响 | 极远源，低频铺垫 |

### Positioning 设计意图
随机声按"远/近、动/静"分布：警笛、闷响 = 远景衰减源；飞行车、载具 = 带移动的 3D 声源；脚步、全息广告 = 近场点源。在 Soundcaster 中改变听者距离/方位即可直观听到音量与声像随距离变化，验证 3D Positioning 与 Attenuation 配置。
